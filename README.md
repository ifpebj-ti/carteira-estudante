# 📘 Carteira do Estudante Interno

---

Projeto focado na **criação de uma carteira de estudante digital** para realizar o controle seguro e prático de entrada e saída de estudantes internos no campus.

Esta aplicação substituirá métodos analógicos, garantindo maior agilidade no acesso ao campus e fornecendo uma interface acessível para os estudantes gerenciarem sua identificação.

---

## 🚀 Funcionalidades Previstas

- 🪪 Geração de carteira de estudante digital  
- 🔄 Registro automatizado de entrada e saída do campus  
- 👨‍🎓 Cadastro e autenticação de estudantes internos  
- 📱 Interface responsiva (mobile e desktop)
